# Interface catalog

This repository has no UI yet. When a change adds one, read the local polish skill first.

- `skills/make-interfaces-feel-better`

Published sources for the same rules, and for the wider `better-*` set (accessibility, color, layout, typography, writing, and a combined review):

- https://jakub.kr/skills
- https://jakub.kr/writing/details-that-make-interfaces-feel-better
- https://github.com/jakubkrehel/make-interfaces-feel-better
- https://github.com/jakubkrehel/skills

The `better-*` skills are not vendored in this repo. Open the published skill for the surface you are changing.

Apply a polish fix in the styling system the project already uses. A polish note does not outrank a broken interaction.
