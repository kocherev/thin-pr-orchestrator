# Notes library

This tree is the sample repository for replay.

## Counter

increment adds one.
decrement subtracts one.

## Format

formatCount renders the number as text.

## Notes

splitNotes breaks on newlines.

## Flags

parseFlag accepts true and false.

## Limits

Callers keep the change small.
A wide edit fails the diff budget.
A long rewrite fails the line budget.
The gate still checks plan, tests, and contracts.
